Evaluation therefore uses the ADVISORY's no-padding path (batch size 1, no pad tokens), which is free of batch composition by construction.

## 5. What changed in the code

- `MedDecideModel.hidden_states` passes explicit `position_ids` counted from the attention mask.
- `collate` rounds the row length to a multiple of `LINEAR_ATTENTION_CHUNK` (64) by default; `round_to_chunk=False` gives a row exactly as long as its longest item (no padding at batch 1).
- `score_items` and `run_student.py --no-chunk-rounding` expose the switch; defaults are unchanged for training.
- Tests: `tests/test_collate_unpadded.py` (layout), `tests/test_paired.py` (metrics), and `tests/test_padding_trained.py` (the probe as a strict expected failure, reason cites this file).
